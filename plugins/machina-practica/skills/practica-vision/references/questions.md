# Intent questions

README: What is it? Who benefits? What exists today? Where is the vision and current work?

VISION: What experience or problem motivates it? What outcomes would make it useful? What principles guide tradeoffs? What is deliberately excluded? What important tensions remain?

Keep the user's domain-specific language. A game vision may value a shared tabletop experience; an authoring tool may value inspectable reproducibility; monitoring may value calm, credible incident awareness. None implies a framework or storage engine.

Do not import licensing from this skill bundle into a new project. Record an unknown license as a decision to resolve before distribution, not a guessed grant.
