# Tool requirements and archives

Choose REQUIREMENTS.md for supplied desired behavior or SOURCE_AUDIT.md when understanding a historical implementation/archive. Identify revision, archive hash, device/version, source authority, access limits, and observable behavior.

For an authoring system, distinguish source component, generated projection, author review, mathematical evidence, and reproducibility inputs. Do not infer TeX, Sage, or a desktop framework from those concepts.

For prior code, inspect immutable revisions and note dirty worktree differences separately. Do not execute untrusted build scripts just to read source. Preserve source bytes in any permitted compatibility corpus; make transformed/normalized derivatives explicit. Record unknown behavior as unknown.
