# A method made repeatable

Experimental skills turn the principles in *Machina Practica* into bounded agent workflows. Each phase should answer one class of questions and produce reviewable evidence before the next begins.

1. State the intent and vision.
2. Understand the domain.
3. Prove a minimal platform scaffold.
4. Design the useful first product.
5. Plan independently reviewable delivery steps.
6. Implement and verify one outcome at a time.

**Status: experimental skills available in source.** The `machina-practica` plugin contains eight `practica-` skills, platform references and a versioned evidence contract. Read the [skill bundle and validation guide](https://github.com/machinapractica/practica/blob/main/docs/SKILLS.md). No project has yet been created with these skills; behavioral evaluation remains ahead.

Read the [project setup proposal](/proposals/project-setup/) for document boundaries, workflows, evidence expectations, and the limits of each phase.
