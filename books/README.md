# The books

*Effective Agents* is the programmer's guide to building reliable software with coding agents. Its [table of contents](effective-agents/README.md) and [first chapter](effective-agents/01-build-deep-sea.md) are drafts for review.

*Machina Practica* walks through the agent skills, explaining their goals, the reasons behind their instructions, and how to check and improve them. Its scope is provisional; no manuscript has been drafted yet.

## Source and editions

Markdown is the canonical manuscript format for both books. Keep one source that people and agents can read, review and edit. Use ordinary headings, relative links and fenced code examples. Keep layout commands and print-specific line breaks out of the prose.

We plan to use Typst to produce professional print editions from the Markdown source. Conversion, page design, fonts and print validation remain future work. There is no print build or PDF edition yet.

## Review

Follow the [website style guide](../docs/WEBSITE_STYLE_GUIDE.md) for the voice. Ground each chapter in the actual source repositories behind the extraction work. Inspect committed documents, implementation and history before drafting. Record exact revisions and claim-to-source links in the book's source notes. Use actual project examples; do not invent a generic process or a fictional project to supply the method. Distinguish observed practice, proposed synthesis and deviations from our standards. A claim that something recurs across all source repositories needs evidence from every repository in that stated set.

Write the chapter as a hands-on manual: give the reader a task, a usable prompt, an expected result and something to try. Keep repository comparisons and prompt-history mappings in editorial source notes. Grounding is the author's research responsibility; the reader should be able to follow the chapter without studying that research. Follow the selected project's actual sequence, incorporating its corrections into the instructions.
