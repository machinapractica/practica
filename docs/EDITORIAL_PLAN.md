# Editorial plan

## Current drafts

*Effective Agents* now opens with [Build a game: Deep Sea](../books/effective-agents/01-build-deep-sea.md), a hands-on exercise adapted from Deepsea's prompt history. The [contents](../books/effective-agents/README.md) lead with that build and then explain its stages. [Editorial source notes](../books/effective-agents/SOURCE_NOTES.md) hold the research and distinguish the observed lobby implementation from the still-planned gameplay steps.

*Machina Practica* is a walkthrough of the agent skills: what each is intended to accomplish, why its instructions are written that way, and how to check and improve it. Its scope remains provisional and its manuscript is not yet drafted.

## Next work

1. Review the opening exercise for practical usability: prompts, prerequisites, expected results and manual checks.
2. Trial the chapter from an empty directory when project creation is authorized. The source project's gameplay steps remain incomplete, so the final exercise is not yet qualified.
3. Complete and verify the gameplay path before describing the tutorial as exercised from start to finish.
4. Draft later chapters as practical explanations of the stages, keeping research comparisons in source notes.
5. Outline Machina Practica around the goals, instructions, examples and checks for each skill.
6. Establish a Typst workflow for professional print editions from the Markdown manuscripts.

## Source and publication

Markdown is the canonical source for both books, readable by people and agents. See the [book source conventions](../books/README.md). Keep print layout separate from the prose. Typst conversion and print validation remain future work.

Eight experimental skills already exist. Their structural checks pass; their behavior in complete new projects remains to be evaluated. Book drafts and illustrative examples are not evidence that those evaluations have run.
